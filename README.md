# DeuLearn

**DeuLearn — Deutsch lernen, von A1 bis C2**
**Creator and copyright owner: Mohammad Farmani**

Copyright © 2026 Mohammad Farmani. All rights reserved.

DeuLearn is a German learning app for levels A1 to C2, with help in English or Persian. Profiles, progress and settings stay on your device, and it works offline.

**Website and downloads: https://mfarmani85.github.io/DeuLearn/**

## Android

Install the official app from [`DeuLearn.apk`](DeuLearn.apk) (version 1.0.0, Android 7.0 or newer, built for Android 16). On your phone, allow "Install unknown apps" for your browser or file manager, then open the APK.

For spoken German, install a German voice: Settings → System → Text-to-speech → Google Speech Services → Install voice data → German.

## iPhone

1. Open **https://mfarmani85.github.io/DeuLearn/** in **Safari** and tap **Open DeuLearn**.
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. Open DeuLearn from your home screen. After the first launch it works offline.

For spoken German: Settings → Accessibility → Spoken Content → Voices → German.
