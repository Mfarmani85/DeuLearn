Android

Android 7 or newer · built for Android 16 · about 3.1 MB

⬇ Download APK v1.0
  1. Download DeuLearn.apk.
  2. If asked, allow Install unknown apps for your browser or file manager.
  3. Open the file and tap Install.

German voice: Settings → System → Text-to-speech → Google → Install voice data → German. Speaking exercises ask for the microphone the first time.

iPhone & iPad

No App Store needed · installs on your home screen

▶ Open DeuLearn web app
  1. Open this page in Safari and tap Open DeuLearn.
  2. Tap the Share button, then Add to Home Screen.
  3. Tap Add and open the app from your home screen. After the first launch it works offline.

German voice: Settings → Accessibility → Spoken Content → Voices → German. Your profile and progress stay on this device.
